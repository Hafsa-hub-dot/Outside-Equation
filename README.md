## المزايا الحالية
- ترحيب وصورة للأم في الواجهة
- نموذج مشاركة الخواطر وتخزينها في Supabase
- معاينة شهادة تقدير وشكر قبل النشر، وإعادة توليدها وطباعتها A4 بعد النشر
- تصفح فاخر للخواطر مع البحث والترتيب والصفحات
- زر نسخ الخاطرة وزر حذف الرسالة مع تأكيد

## سياسة الحذف
بناءً على طلب صاحبة الموقع، **الحذف متاح لأي زائرة دون تسجيل دخول أو رمز بريد**. يطبق ذلك في قاعدة Supabase عبر سياسة DELETE لدوري anon وauthenticated. يجب الانتباه إلى أن أي زائرة يمكنها حذف خواطر الأخريات نهائيًا؛ ولا توجد إمكانية لاسترجاعها من واجهة الموقع. يُنصح بالنسخ الاحتياطي الدوري.
